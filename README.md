# 📁 Java Practice Repository

This repository contains various Java code organized into different branches for better modularity and clarity.

---

## 📌 Branch Structure

- **`main`** – Contains the README and general documentation for the repository.
- **`core-java`** – Basic Java codes including patterns, logic building, and fundamental programs.
- **`DSA`** – Data Structures and Algorithms implemented in Java.
- **`OOPS`** – Object-Oriented Programming concepts with code examples and practice problems.

---

## 🧠 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/AadityaSukhoi/Bridgelabs.git
   ```
2. Navigate into the project:
   ```bash
   cd Bridgelabs
   ```
3. Switch to the Desired Branch:
   ```bash
    git checkout <branch-name>
   ```
